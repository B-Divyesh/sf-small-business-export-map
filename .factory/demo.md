# Demo sandbox

Open `https://small-business-export-map.sociobot.in/demo` or `?demo=1` for the one-click sample.

The sample has three invoice rows, a completed six-column accountant profile, checked output, and CSV/manifest downloads. Demo profiles use the separate IndexedDB database `demo:export-map`; real profiles use `export-map`. The persistent banner offers **Reset demo** and **Start for real**. Reset replaces only the demo database. Start for real never copies demo data into real storage.
